# WeatherIQ — National Weather Big Data Analytics Platform

Full-stack React + Node hackathon prototype.

Features:
- Live weather dashboard
- Location search and browser GPS
- 7-day and hourly forecast
- Historical analytics
- Interactive OpenStreetMap weather map
- Threshold-based disaster risk intelligence
- India Meteorological Department feed when reachable
- Social disaster report verification using public URL metadata, location clues, optional event time, and image GPS EXIF

Run:
```bash
npm install
npm run dev
```
Open http://localhost:5173

Verification is evidence-based corroboration, not proof of authenticity. Official government warnings remain the authority for emergency decisions.
